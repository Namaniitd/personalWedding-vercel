Wedding project source archive from the current working copy.

The HD and 4K teaser videos are intentionally omitted:
- web/private-media/teaser/prewedding-teaser-hd.mp4
- web/private-media/teaser/prewedding-teaser-4k.mp4

The teaser poster, source code, photographs, music, and current uncommitted
project changes are included. Restore the video files at the paths above to
use teaser playback.

Local database content, credentials, Git history, dependencies, build output,
and local test artifacts are excluded. Environment examples are included.
Follow the package READMEs to install dependencies and configure your own
local environment. The local Compose setup also needs your own
api/database/content.local.sql file; private wedding data is not included.
