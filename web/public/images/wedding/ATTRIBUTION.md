# Hindu wedding photography attribution

The source photographs were downloaded from Wikimedia Commons on 7 September
2026. The retained images are kept locally so the invitation has no runtime
dependency on a third-party image host.

The `wedding-mehendi.jpg` rendition is resized to 1920px, with no other edits.
`wedding-mehendi-960.webp` and `wedding-mehendi-1440.webp` are smaller WebP
copies for responsive delivery.

`../invitation-share.png` uses a tinted crop of the hands photograph credited
below as a generic preview for private links. It contains no guest or wedding
details. The original hands file and its other resized copies are no longer
shipped; this credit remains for the share preview.
